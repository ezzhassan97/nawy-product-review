# Nawy product review

A Claude Code plugin for product managers: product reviews for management, built from Jira and GitHub with your
input, published on your own link, with feature demo videos.

```
claude plugin marketplace add ezzhassan97/nawy-product-review
claude plugin install nawy-product-review@nawy-product-review
```

Then, in a new Claude Code session: **"Set up my product review"**.

Everything else (what's inside, what it needs, the zip install, updating): [the plugin's README](plugins/nawy-product-review/README.md).
